# The campaign: a journey through the machine's memory, one region at a time.
# Each region is a run of topics from topics.txt, then a boss: an Exam prep
# problem played under exam conditions. Beat a region's boss to open the next.
#
#   REGION: id | name | what it covers | exam (or -)
#   TOPICS: topic ids from topics.txt, in the order they're played
#   BOSS:   name | problem id from content/practice | look (offbyone, dangling, leaker, shallow)
#   TAUNT:  what the boss says before the fight
#   STORY:  what Mal says on the map while you're in this region
#   WIN:    what Mal says when the boss is beaten
#
# A topic counts as cleared once it's Familiar (50 mastery points) or better.

REGION: stack | The Stack | C basics | Exam 1
TOPICS: basics, control, arrays, strings, functions
BOSS: The Off-By-One | lab1/q15_reverse_array | offbyone

WIN: The Heap is open. Something in there is losing nodes, and I'm made of heap. Let's go.

REGION: heap | The Heap | Memory bugs & linked lists | Exam 2

BOSS: The Leaker | exam2/13_insert_at_position | leaker

STORY: Down here, blocks live until someone frees them. The Leaker feeds on nodes nobody points at any more.
WIN: Not a byte leaked! One region left: Object Land, where C++ classes live.
