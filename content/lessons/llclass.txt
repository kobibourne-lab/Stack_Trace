# Linked list class - deleting a node by value with a cur and a prev pointer,
# from the C++ class version of the linked list in Noel's Pointers in C++ and
# Linked List lecture.
TITLE: A linked list class: deleting a value
TOPIC: llclass
TEXT: Noel's LinkedList class keeps head private, and its methods do the pointer work. Its destructor deletes every node, so the list cleans up after itself.
TEXT: To delete a value, walk two pointers along: cur on the node you're checking, prev one behind it. When cur finds the value, prev's next skips over it.

CODE:
void LinkedList::deleteWithValue(int v)
{
    Node *cur = head, *prev = nullptr;
    while (cur && cur->data != v) {
        prev = cur;
        cur = cur->next;
    }
    if (cur == nullptr) return;
    if (!prev) head = cur->next;
    else prev->next = cur->next;
    delete cur;
}
END
