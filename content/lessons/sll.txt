# Singly linked list - building a list of three nodes, then walking it the way
# PrintList does in the Pointers & Linked List lecture. Each node is one heap
# block, shown as one box per field (n1.data, n1.next).
TITLE: A singly linked list, node by node
TOPIC: sll
TEXT: Each node holds a value and a pointer to the next node. The last one's next is nullptr.
TEXT: head points at the first node. Walk the list by following next until you reach nullptr.

CODE:
struct Node { int data; Node *next; };
Node *head = new Node{1, nullptr};
head->next = new Node{2, nullptr};
head->next->next = new Node{3, nullptr};
Node *cur = head;
while (cur != nullptr)
    cur = cur->next;
END

EXPLAIN: The first node is made on the heap. head points at it, and its next is nullptr: the list ends here.
