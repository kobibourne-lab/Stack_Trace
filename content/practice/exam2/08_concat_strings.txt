PROTOTYPE: void concat_strings(char *dest, char *src);
TEXT: Concatenate two strings using pointers: add src onto the end of dest. You can assume the destination has enough space.
RULE: No array indexing (arr[i]): pointer arithmetic only
FORBID: [ | No arr[i] or [ ] at all: this lab is pointer arithmetic only (use *(p + i) or move the pointer).
HINT: First move a pointer to the '\0' at the end of dest.
HINT: Then copy src from there, including its '\0'.

EXAMPLE:
char dest[20] = "Hello, ";
char src[] = "World!";
concat_strings(dest, src);   // dest = "Hello, World!"
