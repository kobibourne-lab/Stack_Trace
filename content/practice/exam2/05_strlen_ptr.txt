TITLE: String Length
FUNCTION: strlen_ptr
GROUP: Strings
DIFFICULTY: Easy
TOPIC: arith
MINUTES: 10
PROTOTYPE: int strlen_ptr(char *str);
TEXT: Calculate the length of a string (a null-terminated character array) using pointers. Don't call strlen.
RULE: No array indexing (arr[i]): pointer arithmetic only
FORBID: [ | No arr[i] or [ ] at all: this lab is pointer arithmetic only (use *(p + i) or move the pointer).
HINT: Move a pointer along until *p == '\0'.
HINT: The length is how far it moved: p - str.

EXAMPLE:
char str[] = "Hello";
int length = strlen_ptr(str);   // length = 5
END
