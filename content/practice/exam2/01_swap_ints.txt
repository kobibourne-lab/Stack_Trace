PROTOTYPE: void swap_ints(int *a, int *b);
TEXT: Swap the values of two integers using pointers.
RULE: No array indexing (arr[i]): pointer arithmetic only
FORBID: [ | No arr[i] or [ ] at all: this lab is pointer arithmetic only (use *(p + i) or move the pointer).
HINT: *a is the caller's first int. Save it in a temp before overwriting it.

EXAMPLE:

swap_ints(&x, &y);   // Now x = 10, y = 5

    int x = 5, y = 10;
