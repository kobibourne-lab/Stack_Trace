TITLE: Reverse Array
FUNCTION: reverse_array
GROUP: Arrays
DIFFICULTY: Medium
TOPIC: arith
MINUTES: 15
PROTOTYPE: void reverse_array(int *arr, int size);
TEXT: Reverse the contents of an integer array in place, using pointers.
RULE: No array indexing (arr[i]): pointer arithmetic only
FORBID: [ | No arr[i] or [ ] at all: this lab is pointer arithmetic only (use *(p + i) or move the pointer).
HINT: Two pointers: one at the start (arr), one at the end (arr + size - 1).
HINT: Swap what they point at and move them towards each other until they meet.

EXAMPLE:
int arr[5] = {1, 2, 3, 4, 5};
reverse_array(arr, 5);   // arr = {5, 4, 3, 2, 1}
END
