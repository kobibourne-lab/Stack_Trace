PROTOTYPE: void swap_chars(char *a, char *b);
TEXT: Swap the values of two characters using pointers.
RULE: No array indexing (arr[i]): pointer arithmetic only
FORBID: [ | No arr[i] or [ ] at all: this lab is pointer arithmetic only (use *(p + i) or move the pointer).
HINT: The same idea as swap_ints, with a char temp.

EXAMPLE:
char a = 'A', b = 'B';
swap_chars(&a, &b);   // Now a = 'B', b = 'A'
END
