GROUP: Arrays
DIFFICULTY: Easy
TOPIC: arith
MINUTES: 10
PROTOTYPE: int find_max(int *arr, int size);
TEXT: Find the maximum value in an integer array using pointers.
RULE: No array indexing (arr[i]): pointer arithmetic only
FORBID: [ | No arr[i] or [ ] at all: this lab is pointer arithmetic only (use *(p + i) or move the pointer).
HINT: Start with max = *arr, then look at *(arr + i) for the rest.
HINT: Or move a pointer: for (int *p = arr; p < arr + size; p++).

EXAMPLE:
int arr[5] = {3, 9, 2, 8, 5};
int max = find_max(arr, 5);   // max = 9
END
